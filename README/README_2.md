객체지향 I - 클래스와 캡슐화
## ⚙️ 실행 방법
step1.
    사용자로 부터 이름, 전공,기수를 입력받고 입력값 검증후 Lion 객체 생성
step2.
    입력값을 바로 Lion 객체 생성후 객체 내부에서 검증
step3.
    접근 제어자에 따라 내부 클래스 접근 시도
## 💡 작업 내용
- Lion 클래스를 정의하여 아기사자 한 명의 정보를 객체로 표현
  생성자를 통해 객체 생성 시 초기값을 설정
  validate() 메서드를 구현하여 객체 내부에서 상태 검증 수행
  step1에서는 main에서 입력값 검증을 수행하여 책임 분리 구조 설계 
  step2에서는 검증 책임을 Lion 클래스 내부로 이동시켜 객체 중심 설계 
    

## 🤔 느낀 점 / 어려웠던 점
- 내부 클래스를 활용하는 과정에서 구조가 복잡해져 설계를 깔끔하게 만드는 것이 중요하다는 점을 깨달았습니다.
